Connected DVT Prototype
=======================
Start here: index.html

Flow:
1. Login -> landing.html
2. Click an Application No. on the DVT landing/inbox -> dvt-drs.html
3. DVT DRS Quick Links:
   - Open Tasks -> open-tasks.html
   - Previous Policies -> previous-policy.html
   - Audit Trail -> audit-trail.html
4. View Medical(s) -> view-medical.html
5. View Financial(s) -> view-financial.html
6. Back buttons return to dvt-drs.html

Legacy alias files are included so older internal links continue to work.
